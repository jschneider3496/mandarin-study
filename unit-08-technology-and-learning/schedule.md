# Unit 08 — Schedule (6 days)

Rules:
- Quick scan all 40 key words daily.
- Use the focus set for deeper speaking.
- Day 3+ always review earlier days.

## Day 1 🟢
- **Vocab focus:** #1–#10 (technology, accounts, login)
- **Grammar targets:**  
  - tool use: `用…学习…`  
  - balanced view: `有用，但是…`
- **Reading:** Day 1 “新的学习应用”
- **Speaking (constraints):**
  1) Describe one app or website you use for Chinese.  
  2) Use ≥4 words: 软件 / 应用 / 复习 / 有用

## Day 2 🟢
- **Vocab focus:** #11–#20 (files, notifications, homework, review)
- **Grammar targets:**  
  - inability: `登录不了 / 打不开 / 收不到`  
  - troubleshooting: `先…再…`
- **Reading:** Day 2 “登录不了账号”
- **Speaking (constraints):**
  1) Roleplay: ask for help with a login or password problem.  
  2) Use ≥4 words: 账号 / 密码 / 网络 / 重新

## Day 3 🟡 (Review Day 1)
- **Vocab focus:** #21–#30 (progress, usefulness, convenience)
- **Review:** summarize Day 1 in 2 sentences.
- **Grammar targets:**  
  - deadline: `八点前必须…`  
  - problem priority: `先解决这个问题`
- **Reading:** Day 3 “上传作业”
- **Speaking (constraints):**
  1) Explain a homework upload problem and next step.  
  2) Use ≥5 words: 通知 / 上传 / 文件 / 解决 / 作业

## Day 4 🟡 (Review Day 2 + Day 1)
- **Vocab focus:** #31–#40 (problems, persistence, limits, connectors)
- **Grammar targets:**  
  - past vs now: `以前…现在…`  
  - benefit: `对提高水平有帮助`
- **Reading:** Day 4 “不能太依赖翻译”
- **Speaking (constraints):**
  1) Compare an old study habit and a new study habit.  
  2) Use ≥4 words: 依赖 / 熟悉 / 提高 / 水平

## Day 5 🔴 (Review Days 1–3)
- **Focus:** pick 10 weak words across #1–#40.
- **Grammar targets:**  
  - especially: `尤其是…`  
  - realistic plan: `虽然…但是…`
- **Reading:** Day 5 “坚持练习才有进步”
- **Speaking (constraints):**
  1) Give a realistic weekly study plan with one limitation.  
  2) Use ≥6 earlier words.

## Day 6 🔴 (Review Days 1–5)
- **Review:** 6-sentence tech-learning recap (tool + problem + fix + progress).
- **Grammar targets:**  
  - troubleshooting chain: `如果还不行，就…`  
  - report situation: `发消息说明情况`
- **Reading:** Day 6 “解决技术问题”
- **Capstone roleplay (3–5 minutes):**
  - You and GPT: learning app → login problem → homework upload → translation habit → study progress.  
  - Constraints: 3–4 sentences/turn; reuse ≥8 ⭐ Core words; include one troubleshooting sequence.
