# Mandarin Study Pack (HSK 3.0–inspired L1–L4)

This pack is designed for **reading + speaking** using **simplified characters** and **tone-mark pinyin**.

- No handwriting practice
- Optimized for **speech-to-text** (answer in characters; pinyin is OK)
- 4 units × 6 days each
- Each unit has **40 key words** (targets). Readings may include extra simple words (listed in a mini glossary).

## How to use (20–30 min/day)

1) **Vocab (8–10 min)**  
   Pick the day’s focus set from `schedule.md`. Do fast recall out loud: EN → ZH, then ZH → EN.
2) **Reading (8–10 min)**  
   Read **simplified-only** first. Use pinyin only when stuck. Check English last.
3) **Speaking (8–10 min)**  
   Do the prompts in `schedule.md`, then start a fresh GPT chat using either:
   - `tutor.md` (top-level, works for any unit/day), or
   - the unit’s `tutor.md` (more specific)

## When to advance

Move on when you can:
- Understand **~70–80%** of the simplified-only reading on first pass
- Roleplay for **3–5 minutes** using mostly unit vocabulary
- Keep recurring grammar mistakes to **≤3**, or self-correct after feedback

## Grammar roadmap (global progression)

- **Unit 1 (Self-intro):** basic questions (吗/呢), 是/不/没, 的, time/place basics
- **Unit 2 (Eating out):** 想/要, polite requests (可以…吗 / 能不能…), ordering patterns, 再/还/一点儿, prices
- **Unit 3 (Travel):** 了 (completed), 过 (experience), sequencing (先…再…), 因为…所以…, opinions (觉得)
- **Unit 4 (Work):** ability/need (会/能/应该/需要), plans (打算/计划), responsibilities (负责), simple reporting

## Optional pronunciation / tone workflow (no audio files required)

- If a word is hard: play it in any dictionary/TTS 3–5 times, then repeat it 5 times.
- Shadow 1–2 lines/day: listen → repeat 3 times → record yourself → compare.
- Ask GPT for tone hints and short “repeat after me” drills (text-only).
